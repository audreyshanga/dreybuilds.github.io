a simulator for testing robot movements

a react interface and python backend let you inspect robot state and try movement policies.

Robotics / Physical AI Robotics · Python / FastAPI · MuJoCo

My contribution: The original idea, project leadership, and ongoing direction. I also made the linked project video.

Built together: A collaborating developer contributed substantial implementation work. The project now includes a completed MuJoCo backend.

The public simulator pairs a React interface with a Python backend. It reads robot state through Origin, computes controls, and sends actions back to the simulator. Users can select movement policies, inspect live state, and send manual actions.
