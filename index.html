02 — ROBOTICS & CONTROL

Origin

Original concept & project direction

A robotics project connecting software to simulated and physical devices. I originated the idea and lead its direction, from the problems we explore to what we build next.

RoboticsPython / FastAPIMuJoCo
Watch my Origin demo ↗
My role & the build +

My contribution: The original idea, project leadership, and ongoing direction. I also made the linked project video.

Built together: A collaborating developer contributed substantial implementation work. The project now includes a completed MuJoCo backend.

The public simulator pairs a React interface with a Python backend. It reads robot state through Origin, computes controls, and sends actions back to the simulator. Users can select movement policies, inspect live state, and send manual actions.

03 — TEST AUTOMATION

Automated test platform

A Python-driven test platform for pumps, valves, and batteries. Distributed edge devices collect telemetry, turning long hardware test cycles into actionable data.

PythonRaspberry PiInfluxDBGrafana
The build story +

My role: Lead engineer on the automated test platform at KOKO Networks.

I developed the Python automation and moved test data from CSV files into InfluxDB, with EC2 storage, S3 backups, and Grafana dashboards. Raspberry Pi and RP2040 nodes extended testing across multiple points.

The result: Test cycles reduced from 12 months to 2 months, as documented in my CV.
